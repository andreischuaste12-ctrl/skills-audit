**What the new version does**

2. Builds the email from the named template and runs a pre-send checklist.
3. Sends a test first. It checks the script's `--help` rather than assuming a dry-run flag exists.
4. Shows a summary (list, recipient count, subject, time, test result) and waits for an explicit "yes".
5. Sends once, with no automatic retry, because a partial failure may already have reached some recipients.
6. Checks the exit code and status, then reports the real outcome, including failures.
