## Suggested corrected body

```
1. Locate the CSV the user provided. If it is missing or unreadable, say so and ask for it. Never invent data.
2. Detect the delimiter and encoding; state what you found. Ask if ambiguous.
3. Parse with a real CSV parser. Treat empty cells as missing and count them per column; do not convert them.
4. Report: file name, delimiter, data rows (excluding header), column names, missing counts per column, malformed rows.
5. List only the checks you actually ran. If none, say the results were not independently verified.
```
