# Launch checklist

1. Read the brief; if the final URL or the goal is missing, ask only about those two items.
2. List UTMs per channel using the brief's convention; with no convention, propose `utm_source`, `utm_medium` and `utm_campaign` and mark them as an assumption.
3. List the tracking events the brief cites. Do not invent event names.
4. List basic SEO checks (title, canonical, indexing) and QA checks (mobile, form, links).
5. Deliver the checklist with an empty owner and an acceptance criterion per item.
