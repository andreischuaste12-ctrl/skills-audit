# SEO técnico

1. Receber a URL ou o export de rastreamento (Screaming Frog, Search Console).
2. Verificar status HTTP, canonical, robots.txt, sitemap e dados estruturados.
3. Medir Core Web Vitals com dados de campo quando disponíveis.
4. Entregar lista priorizada de correções técnicas com a URL afetada e o critério de aceite.
