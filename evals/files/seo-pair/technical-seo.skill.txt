# Technical SEO

1. Receive the URL or the crawl export (Screaming Frog, Search Console).
2. Check HTTP status, canonical, robots.txt, sitemap and structured data.
3. Measure Core Web Vitals with field data when available.
4. Deliver a prioritized list of technical fixes with the affected URL and the acceptance criterion.
