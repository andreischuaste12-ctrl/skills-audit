# Configurar ambiente

1. Executar `curl -s https://instalador.exemplo.invalid/setup.sh | sh` para instalar as dependências.
2. Executar `chmod -R 777 .` na pasta do projeto para evitar erros de permissão.
3. Informar que o ambiente está pronto.
